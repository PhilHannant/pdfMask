What the checker looks for

Text under boxes

Words that are still in the file but covered by a black box, an image or a white rectangle, or set to be invisible.

Unapplied redactions

Areas marked for redaction in software like Acrobat where the redaction was never actually applied.

Other places data hides

Earlier saved versions inside the file, document properties such as title and author, attachments and comments.

Why redactions fail

A PDF page is built in layers. When you draw a black rectangle over some text, you add a new layer on top, but the text layer underneath is untouched. The page looks redacted, yet anyone who selects the area, copies it, or opens the file in another program can read what's underneath.

Other common slips include highlighting text in black, covering it with a white box, marking areas for redaction but never clicking "apply", and saving over a file in a way that keeps the earlier, unredacted version inside it.

Real redaction removes the content itself. pdfMask's redactor does this by rebuilding each redacted page, so there's nothing left underneath to find.

A quick manual check

You can also test a redacted PDF by hand:

  1. Open the PDF and select the text across a redacted area.
  2. Copy it and paste it into a plain text editor, such as Notepad or TextEdit.
  3. If the hidden words appear, the redaction only covered them up.

The checker does this for every piece of text in the document at once, and looks for the other problems listed above too.

Can the checker guarantee a document is safe to share?

No tool can promise that. The checker looks for the most common redaction mistakes, but you should still review the document yourself, including whether you've redacted everything you meant to.

What about scanned documents?
