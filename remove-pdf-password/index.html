Remove a password from a PDF

Tired of typing the same password every time you open a statement or payslip? Enter it once and save a copy that opens without it. Your file and your password never leave your device.

Remove the password

Choose your PDF, then enter its password when asked.

How to remove a PDF password

  1. Choose the password-protected PDF above. It's opened in your browser and never uploaded.
  2. Type the password you normally use to open it.
  3. Click Unlock & Download. A copy that opens without a password is saved with -unlocked added to the name.

When this is useful

  • Bank statements, payslips and pension letters that arrive protected with your date of birth or postcode.
  • Documents you need to merge, redact, print or upload to another service that can't open protected files.
  • Archiving your own files so they'll still open years from now, when the password is long forgotten.

Keep the unlocked copy safe

Once the password is removed, anyone who gets hold of the file can open it. Store the unlocked copy somewhere secure, and think twice before emailing it. If you only need to share part of it, redact the details you don't need to send first.

pdfMask can only remove a password you know. It doesn't guess or crack passwords. Only unlock documents you own or have permission to use.

Frequently asked questions

Can I remove a PDF password if I don't know it?

No. You need the correct password to open the file. pdfMask doesn't guess or crack passwords. If you've forgotten it, ask whoever sent you the document.

Is my password sent anywhere?

No. The password and the PDF stay in your browser. They're only used on your device to open the file and save an unprotected copy.

Does removing the password change the document?

Only the protection is removed. Text, images, links, bookmarks and form fields are kept, and your original file isn't changed.

My PDF opens without a password but won't let me print or copy

That's a restricted PDF rather than a password-protected one. The same tool handles it, with no password needed. See Unlock PDF.
